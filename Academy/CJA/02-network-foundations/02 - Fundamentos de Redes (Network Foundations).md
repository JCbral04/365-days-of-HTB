
## ¿Qué es una red?

Podriamos definirlo como un conjunto de dispositivos que se encuentran conectados para compartir recursos e información.

## Topologías

- ****Física:**** cómo están cableados (estrella, bus, anillo, malla)
- ****Lógica:**** cómo fluye la información (la que importa para VLANs)

## Tipos de red (por alcance)

|   |   |
|---|---|
|Tipo|Alcance|
|PAN|Dispositivos personales (Bluetooth)|
|LAN|Hogar/oficina/edificio|
|WAN|Ciudades/países (Internet es la WAN más grande)|
|MAN|Ciudad/metropolitana|
